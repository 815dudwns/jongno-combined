# Handoff: 종로 합동시공 지도 — 클레이모피즘 리디자인

## 개요 (Overview)
종로구 전기계량기 합동시공(교체) 현장 작업용 **모바일 웹앱**의 UI를 **클레이모피즘(Claymorphism)** 스타일로 리디자인한 패키지입니다.
기존 앱(`jongno-combined`)은 플랫한 네이비/블루 + 이모지 기반이었고, 이번 리디자인은 **웜 크림 배경 + 세이지 민트 강조**의 부드러운 입체(클레이) 표면, 알약형 곡선, 소프트 그림자로 통일합니다.

핵심 원칙:
- **이모지·아이콘폰트 완전 배제.** 모든 아이콘은 순수 CSS 도형 또는 인라인 SVG로 구현 (체크·카메라·QR·돋보기·핀·계기·×·줌 등).
- **단일 디자인 시스템** `clay.css` 의 CSS 변수(토큰) + 프리미티브 클래스로 모든 화면 구성.
- 한글 UI, 모바일 세로(390×844 기준) 우선.

## 디자인 파일에 대하여 (About the Design Files)
이 번들의 `screens/*.html` 파일은 **HTML로 만든 디자인 레퍼런스(프로토타입)** 입니다 — 의도한 외형·동작을 보여주는 목업이며, **그대로 복사해 출시하는 프로덕션 코드가 아닙니다.**

작업의 목표는 이 HTML 디자인들을 **대상 코드베이스의 기존 환경에서 재현**하는 것입니다.
- 기존 `jongno-combined` 앱은 **바닐라 HTML/CSS/JS**(빌드 도구·프레임워크 없음, 카카오맵 SDK + Firebase)입니다. 따라서 가장 자연스러운 적용은 **기존 `css/*.css` 파일을 clay.css 토큰 기반으로 교체/확장**하고, 기존 DOM 구조에 클래스를 매핑하는 것입니다.
- 각 프로토타입은 데모용 **폰 프레임(.phone/.phone-screen)** 과 **모의 데이터/모의 카메라·사진** 을 포함합니다. 이는 실제 앱에 넣지 말고, **내부 콘텐츠와 clay.css 스타일만** 이식하세요.

## 충실도 (Fidelity)
**High-fidelity (hifi).** 최종 색상·타이포그래피·간격·그림자·상호작용까지 확정된 픽셀 단위 목업입니다. 개발자는 `clay.css`의 토큰/프리미티브를 그대로 사용해 UI를 **픽셀에 가깝게 재현**하면 됩니다. 색상 hex, 그림자 레시피, radius 값이 모두 토큰에 정의되어 있습니다.

`--radius: 22px` (카드) · `--radius-sm: 14px` (작은 카드/입력) · `--radius-pill: 999px` (버튼/칩/세그먼트)

### 그림자 (Shadows) — 클레이 레시피
광원은 **좌상단**, 음영은 웜그레이. `--depth`(기본 1)로 입체 강도 일괄 조절.
- `--clay` : 볼록 큰 표면 (카드)
- `--clay-sm` : 볼록 작은 표면 (버튼·칩·작은 카드)
- `--clay-inset` : 오목 (입력칸·트랙)
- `--clay-inset-sm` : 오목 작은 (눌림 상태·세그먼트 배경)
- `--clay-mint` : 민트 컬러 볼록 (주요 버튼)
- `--focus-glow` : `0 0 0 3px rgba(70,224,163,.45), 0 0 14px rgba(70,224,163,.35)` (포커스 링)

> 정확한 box-shadow 다중값은 `clay.css` 참조. 그대로 복사해 사용하세요.

### 타이포그래피 (Typography)
- 폰트: **Pretendard** (variable, weight 400–800), CDN `@font-face` 로딩. 폴백: `-apple-system, BlinkMacSystemFont, 'Apple SD Gothic Neo', 'Malgun Gothic', sans-serif`
- 스케일 (관측값): 본문 12–16px / 라벨 11–13px / 카드 제목 15–19px / 화면 타이틀 18–25px / 강조 숫자 24–34px
- weight: 본문 600, 라벨/버튼 700–800, 제목/숫자 800
- letter-spacing: 제목 `-0.02em`, 본문 0

## 프리미티브 클래스 (clay.css 제공)
| 클래스 | 설명 |
|---|---|
| `.clay` / `.clay-sm` | 볼록 표면 카드 (큰/작은) |
| `.clay-inset` | 오목 표면 (입력 컨테이너) |
| `.cbtn` | 기본 버튼 (알약형, 볼록) — `:active` 시 눌림 |
| `.cbtn-primary` | 주요 버튼 (민트 그라데이션 `linear-gradient(145deg,#bbe8d0,#93d2af)`, `--clay-mint`, 라벨색 `--mint-deep`) |
| `.cseg` + `button.active` | 세그먼트 토글 (오목 트랙 + 볼록 활성 알약) |
| `.cinput` | 입력칸 (오목, 알약형, 포커스 시 민트 글로우) |
| `.cchip` (+`.blue/.amber/.rose/.violet/.gray`) | 칩/배지 |
| `.cdot` (+색상) | 상태 점 (이모지 대체, 11px 원형) |
| `.calert` (+`.success/.warning/.error`) | 알림 바 |

**상호작용 공통:** 모든 볼록 요소는 `:active` 시 `transform: translateY(1px)` + `box-shadow`를 `--clay-inset-sm`(눌림)으로 전환. 전환 시간 `.12s`. 포커스 입력은 `--focus-glow` 링.

## 화면별 명세 (Screens / Views)

### 1. 로그인 — `screens/로그인.html`
- **목적**: 작업자 로그인 (아이디/비밀번호)
- **레이아웃**: 세로 중앙 정렬. 로고 타일(92×92, radius 26, 볼록) + 한옥 지붕 SVG 마크(세이지 민트) → 타이틀 "종로 합동시공 지도"(25px/800) → 버전 → 폼.
- **컴포넌트**: 라벨 + `.cinput`(아이디/비밀번호) 2개, 에러 메시지 영역(중앙, `#c14f4f`), `.cbtn-primary` 전체폭 로그인 버튼, 하단 "사용설명서 보기" 링크(상단 구분선 + 볼록 알약).
- **동작**: 빈 값 시 에러 표시, 로그인 중 버튼 비활성+텍스트 변경. (실제 앱은 `auth.js`의 `authLogin` 연결)
- **비고**: 한옥 지붕 = 종로 모티프(처마+기둥+기단 SVG). "한전KDN 강북지사" 문구 없음.

### 2. 지도 — `screens/지도.html`
- **목적**: 현장 지도 + 작업 마커 + 필터/토글
- **레이아웃**: 전체화면 지도(스타일라이즈 SVG: 블록·도로·청계천) 위에 떠있는 클레이 크롬(`.chrome` absolute).
- **컴포넌트**:
  - **좌상단 필터** (`.filters`, z-index 25): "동그룹"·"검침일" 토글 버튼 → 클릭 시 드롭다운 패널(볼록 카드, 클레이 체크박스 `.cbox`, 동별 색 스와치). **드롭다운은 다른 떠있는 요소 위로 떠야 함(z-index).**
  - **우상단 유저바** (`.user-bar-clay`): 작업자명 · 검색 · 로그아웃 알약.
  - **우측 admin 토글** (`.top-toggles`, 우측 정렬): "계기팀 시각/통신팀 시각" + "검침일/우선순위/둘다" — `.cseg` 세그먼트. **admin 전용**이며 좌측 필터와 분리해 간섭 방지.
  - **우하단** (`.map-controls`): 줌 +/− 스택, 현재위치 버튼(클레이 동심 타깃 도형, 활성 시 민트).
  - **마커** (`.marker`): 머리 34px 원형 + **하단 포인터(▼ 마크가 아래로)** + 숫자(계기 수). 상태색: green(완료)·gray(완료처리)·blue(통신)·red(불가)·amber(보류). 검침일 라벨(D17 등) 옵션. **주의: 데모는 34px로 키웠으나 실제 앱 마커는 더 작음(원본 marker.css 20×26 기준 축소 적용).**
  - 현재위치 펄스 점, 토스트.
- **동작**: 필터 드롭다운 열림/외부클릭 닫힘, 체크박스 토글, 세그먼트 전환, 위치버튼 활성, 마커 탭 토스트.

### 3. 주소 상세 — `screens/주소상세 v2.html`
- **목적**: 마커 탭 시 뜨는 풀페이지 오버레이 — 한 주소의 계기 목록 + 작업 상태
- **레이아웃**: 상단 상태 색상 바(5px) → 헤더 → 액션 → 정렬 → 계기 리스트(스크롤).
- **컴포넌트**:
  - **헤더**: 주소(16.5px/800)·도로명·작업자 칩. 우측에 **길찾기 아이콘 3개(T/N/K, 클레이 톤 채도 낮춤: T=뮤트로즈 `#d68f84→#c06f64`, N=세이지 `#84c79c→#5aa477`, K=뮤트골드 `#ddc079→#cba94f`) 가로 + × 닫기**.
  - **완료/보류/불가** 액션(`.act-btn`, 단일 선택, 각 green/blue/rose 활성).
  - 계기 검색(`.cinput` 축소) + 초기화, 공통주 안내(블루), **중복/제조사 정렬** 토글.
  - **계기 카드** (`.meter`): 좌측 칸에 **체크박스 + No.(daily_seq 배지, 바이올렛) 세로**. 본문: 타입 배지 + 계기번호(세그먼트 색상: 제조사/타입(블루)/중복(빨강)) + 복사. 한 줄 요약(제조사·방식·제조). **철거↔새 계기 비교 블록**(철거번호 / 화살표 / 새번호, 미등록은 "미등록"). 사진 칩(장수), 상태 배지.
  - **상태별 카드 톤**: 완료=하늘색, 미완료=기본, 임시저장=점선 노랑+봉인경고, 불가=레드+취소선.
- **daily_seq**: 그날 통합 작업 순번 No.N — 완료/임시저장 계기에 표시.

### 4. 계기교체 등록 모달 — `screens/계기교체모달.html`
- **목적**: 계기 교체 입력 (철거 ↔ 새 계기) — 바텀시트
- **레이아웃**: 바텀시트(`.modal`, 상단 그립). 헤더(제목·주소 / **daily_seq 카운터 −N+ No.** / ×). 본문 스크롤. 푸터.
- **핵심 도메인 로직 (중요)**:
  - **철거 계기번호** = 이미 할당된 값 → **읽기전용 표시**(`.ro-block`, "할당됨" 태그). 입력·사진 없음.
  - **철거 지침 개수 = 계기 종류에 따라 1·2·4개로 강제** (사용자 임의 선택 아님). 데모는 `.case-seg`로 전환하나, 실제는 계기종류로 결정. 케이스별 레이아웃:
    - **1지침**: 지침1(사진 작게+값 가로) → 새계기 (세로 스택, 전체폭)
    - **2지침**: 지침1 지침2 (2열) → 새계기 (전체폭)
    - **4지침**: 지침1 지침2 / 지침3 지침4 → 새계기 (전체폭)
    - CSS: `.layout.case-1/2/4` 가 `.rd[data-i]` 표시/숨김 + grid 배치 제어.
  - **각 철거 지침** = 사진(`.photo`, 카메라 도형) + 지침값 입력.
  - **새 계기**: **QR 스캔 버튼이 최상단·가장 큼**(`.qr-main`, 다크 + QR 도형 — 가장 중요한 입력 경로). 그 아래 계기번호 사진, 계기번호 입력 + **GLAB 키패드 한 줄**(수기 입력 시에만 사용, G/L/A/B 4키, 백스페이스 없음), 제조년월 셀렉트 2개. **새 지침 없음.**
  - **철거 추가 데이터**: 철거 지침과 새계기 **사이(새계기 위)**, 철거 톤(슬레이트). 컴팩트 한 줄. **"+ 항목 추가" 누를 때만** 입력 행(항목/값/사진/삭제) 생성.
  - **푸터**: 삭제 / 임시저장(앰버) / 취소 / **저장(민트, 전체폭)**.
- **동작**: seq 증감, 케이스 전환(레이아웃), 사진 토글, GLAB 입력, 항목 추가/삭제.

### 5. QR 스캔 오버레이 — `screens/QR스캔.html`
- **목적**: 새 계기번호 QR/바코드 스캔 (계기교체 모달 QR 버튼이 엶)
- **스타일**: **다크 클레이** (카메라 화면이므로 배경 어둠 유지, 헤더/프레임/컨트롤만 클레이).
- **컴포넌트**: 헤더(카메라 선택 다크 드롭다운 + 닫기) · 카메라 뷰(모의 피드 + 계기 박스) · **민트 스캔 프레임**(코너 브라켓 + 글로우, 움직이는 스캔 라인 애니메이션) · 안내 텍스트 · **인식 성공 토스트**(클레이 민트, 체크 + 계기번호) · 하단 컨트롤(카메라 전환 / 줌 −/+, 다크 클레이).
- **동작**: 카메라 전환, 줌 ±, 인식 시연(3초 후 토스트, 탭 재시연). 실제는 `qr-scanner.js` 연결.

### 6. 검색 모달 — `screens/검색.html`
- **목적**: 주소·계기번호 검색
- **로직**(원본 `map.js runSearch`): **4자 이상** 입력, 주소/도로명/공동주택명/계기번호 매칭. 결과 행: primary(주소 or 계기번호) + secondary(도로명·아파트) + 메타(동그룹·검침주차 칩).
- **컴포넌트**: 상단 시트. 검색 입력(오목 알약 + 돋보기 도형) + 민트 검색 버튼. 힌트(N건/4자 이상). 결과 리스트: **타입 아이콘**(주소=민트 핀 / 계기=블루 계기 도형), 검색어 **민트 하이라이트**(`mark`), 중복번호 빨강, 동그룹(민트칩)·검침주차(바이올렛칩).
- **동작**: 검색·엔터, 행 탭.

### 7. 사진 뷰어 — `screens/사진뷰어.html`
- **목적**: 등록된 현장 사진 확대 보기 (admin 사진 모달 대체)
- **스타일**: 다크 배경 + 클레이 컨트롤.
- **컴포넌트**: 헤더(계기번호·주소·작업자 + 닫기) · 메인 사진(`.photo-frame`, 3:4, 모의 계기 사진 + EXIF 오버레이: 촬영시각/GPS + 비네팅) · 캡션 배지(철거=회색/설치=민트 `.cdot`) + 카운터(N/4) · **썸네일 스트립 4장**(철거 계기·지침 / 설치 계기·지침, 활성=민트 링).
- **동작**: 썸네일 탭 전환, 메인 사진 좌/우 탭 스와이프. 실제는 `old_photo/new_photo/지침 사진` URL 연결.

## 상호작용 & 동작 요약 (Interactions & Behavior)
- **눌림 피드백**: 볼록 → 오목 전환 (`box-shadow: --clay-inset-sm` + `translateY(1px)`), `.12s`.
- **포커스**: 입력칸 `--focus-glow` 민트 링.
- **세그먼트/토글**: 활성 옵션만 민트 볼록, 나머지 투명.
- **드롭다운/오버레이**: z-index 레이어링 주의(지도 필터 드롭다운이 토글·유저바 위로).
- **스캔 라인**: `@keyframes scan` 2.4s 왕복, 무한.
- **prefers-reduced-motion**: 적용 시 스캔/펄스 애니메이션은 정지 권장.

## 상태 관리 (State Management) — 실제 구현 시
- 로그인 세션(`auth.js`), 지도 마커/필터/뷰모드, 주소별 작업상태(완료/보류/불가), 계기별 교체 데이터(철거번호[읽기]·지침[1/2/4]·새번호·제조년월·사진·봉인 등 추가데이터), daily_seq 카운터, 검색어/결과, 사진 인덱스.
- 기존 앱은 Firebase + 로컬 데이터(`jongno-site-data.json`, `jongno-work-status.json`) 사용.

## 에셋 (Assets)
- **외부 폰트**: Pretendard (jsDelivr CDN, `@font-face`). 사내망 환경이면 폰트를 번들에 포함하세요.
- **아이콘**: 전부 CSS 도형/인라인 SVG — 별도 에셋 없음. (체크·카메라·QR·돋보기·핀·계기·×·줌·카피·한옥지붕 등)

- **브랜드**: 길찾기 T/N/K는 클레이 톤으로 채도를 낮춘 자체 표현(원본 브랜드 로고 아님). 실제 적용 시 정책에 맞게 조정.

## 적용 권장 순서
1. `clay.css` 를 기존 앱에 추가하고 `:root` 토큰을 전역 적용.
2. 기존 `common.css` 의 폰트/배경/버튼/입력 기본을 clay 프리미티브로 교체.
3. 화면별로 기존 DOM에 clay 클래스를 매핑 (로그인 → 지도 → 주소상세 → 모달 → QR/검색/사진뷰어).
4. 이모지 제거: 기존 📡📷✅⏸️❌🗑📊◎ 를 대응 CSS 도형/`.cdot`/SVG로 교체.
