지도 화면 보기

마커 색깔이 의미하는 것

지도 위 동그라미 마커가 작업 대상지입니다. 색깔은 검침일에 따라 달라집니다.

빨강 / 주황 / 노랑검침일별 색상 구분
초록검침일별 색상 구분
파랑 / 보라검침일별 색상 구분
회색완료한 주소 (이미 처리됨)

화면 위쪽 버튼들

  • 동그룹 ▾ — 어느 동을 볼지 선택 (체크박스로 다중 선택)
  • 검침일 ▾ — 검침일별로 필터링 (오늘 처리할 검침일만 보기 가능)
  • ◎ (오른쪽 아래) — 내 위치로 지도 이동 / 추적 토글
  • 로그아웃 (오른쪽 위) — 끝낼 때만 사용
📍 GPS 추적 모드 ◎ 버튼을 다시 누르면 폰 이동에 따라 지도가 따라옵니다. 한 번 더 누르면 해제.

작업 주소 열기

지도에서 마커를 탭하면 그 주소의 상세 패널이 열립니다.

패널 위쪽 — 주소 + 길찾기

  • 도로명·지번 주소가 같이 나옵니다. 주소 옆 작은 복사 아이콘을 누르면 주소가 복사돼서 다른 앱(문자 등)에 붙여넣기 가능.
  • 티맵네이버카카오 — 해당 앱으로 바로 길찾기.

패널 가운데 — 작업 상태

그 주소에 등록된 계기 리스트가 표시됩니다. 각 계기마다 체크박스가 있고 계기번호·제조사·검침일 정보가 보입니다.

  • 중복 정렬 — 변대주(뒤 2자리) 같은 계기끼리 묶어서 정렬
  • 제조사 정렬 — 제조사별 묶음 정렬
  • 계기 검색 ✕ — 계기 끝번호 2자리 이상 입력하면 빠른 찾기
🟡 "추가" 노란 배지 엑셀에 없던 계기를 현장에서 직접 추가한 것입니다. 옆에 🗑 휴지통을 누르면 삭제됩니다.
4

계기 교체 등록 (핵심 작업)

리스트에서 교체할 계기를 탭하면 계기 교체 등록 모달이 열립니다. 5가지를 입력하세요.

📷 ① 기존 계기 사진 (탭하여 선택)
앨범에서 사진 선택
📷 ② 새 계기 사진 (탭하여 선택)
앨범에서 사진 선택
③ 철거 제번 (kWh)
예: 12345
④ 새 계기번호 [QR]
QR 또는 직접 입력
⑤ 제조년월
2026년 · 5월

사진 입력 (① ②)

📂 사진은 앨범에서 고르기 카메라가 아니라 이미 찍어둔 사진을 앨범에서 선택합니다. 미리 사진을 다 찍어두고 앨범에서 가져오세요.

선택한 사진은 자동으로 압축·업로드됩니다 (1280px, 약 200KB 수준).

철거 제번 (③)

철거하는 기존 계기의 현재 검침값(kWh)을 숫자로 입력합니다.

새 계기번호 (④) — QR 스캐너 사용

📷 QR 버튼을 누르면 카메라 화면이 뜹니다.

  • 새 계기 QR/바코드를 사각 박스 안에 맞추세요.
  • 인식되면 자동으로 번호가 입력되고 카메라가 꺼집니다.
  • 줌이 부족하면 ➕ 줌 / ➖ 줌 으로 조절.
  • 카메라가 여러 개면 🔄 카메라 로 전환.
  • 인식 안 되면 ✕ 닫고 직접 입력해도 됩니다.
🔤 AMIGO 계기 (영문 포함) QR 스캔 시 A / B / G / L 같은 영문 prefix는 자동으로 보존됩니다. 특수문자(하이픈, 공백)는 자동으로 제거.

제조년월 (⑤)

드롭다운에서 연도 + 월을 선택. 기본값이 채워져 있으니 다르면 바꾸세요.

저장

모든 항목 입력 후 저장 누르면 Firebase에 즉시 저장됩니다.

  • 상단 "오늘 N번째" 카운터가 자동으로 매겨집니다 (작업자별 일일 일련번호).
  • 저장 즉시 다른 기기에서도 똑같이 보입니다.
  • 관리자 통계 페이지에 사진까지 자동 반영.
📡 통신 끊겨도 네트워크 일시 끊김 시에는 큐에 저장돼 복구되면 자동 업로드됩니다. 너무 오래 끊기면 화면에 경고가 나옵니다.
5

계기 추가 · 수정 · 삭제

➕ 계기 추가 — 엑셀에 없는 계기를 발견했을 때

리스트 위쪽 + 계기 추가 버튼.

  • 계기번호 11자리 입력.
  • AMIGO 같이 영문이 들어가면 A B G L 보조 버튼 활용.
  • ⌫ 로 한 글자씩 지우기.
  • 추가된 계기는 추가 배지로 표시됩니다.

✏️ 수정 — 잘못 입력했을 때

이미 교체 등록한 계기 옆 ✏️ 수정 버튼.

  • 기존 입력 내용이 그대로 채워진 상태로 모달이 열립니다.
  • 사진을 다시 선택하지 않으면 기존 사진 그대로 유지됩니다.
  • 고친 부분만 바꾸고 수정 저장.

🗑 삭제

현장 추가 계기(노란 "추가" 배지) 옆 🗑 휴지통 아이콘. 잘못 추가한 경우만 삭제됩니다 (엑셀 원본은 삭제 불가).

6

작업 완료 처리

주소 패널 위쪽에 3개의 상태 버튼이 있습니다.

✅ 완료 ⏸️ 보류 ❌ 불가

✅완료 — 그 주소의 작업이 다 끝났을 때. 마커가 회색으로 바뀌고 패널이 닫힙니다.
⏸️보류 — 일단 다음에 하기. 주소가 보류 상태로 표시됩니다.
❌불가 — 작업이 불가능한 사유가 있을 때. 누르면 "불가 사유" 입력칸이 나옵니다 (예: 부재중, 단전, 계기 분실 등).
🔄 다시 누르면 초기화 이미 선택한 상태(완료/보류/불가) 버튼을 한 번 더 누르면 미처리 상태로 되돌립니다.
💡 핵심 흐름 ① 계기마다 교체 등록 → ② 다 끝나면 ✅ 완료. 계기 교체 등록 자체가 그 계기에 대한 처리이고, "완료" 버튼은 그 주소 작업이 전체적으로 끝났음을 표시합니다.

자주 묻는 것 · 팁

Q. 다른 사람이 작업한 게 안 보여요

새로고침해보세요. 보통 30초 안에 자동 동기화됩니다. 그래도 안 보이면 로그아웃 후 다시 로그인.

Q. 폰을 바꿨는데 작업한 게 보이나요?

네. 모든 데이터는 Firebase 서버에 저장되니까 어떤 폰에서 로그인해도 똑같이 보입니다.

Q. 사진을 미리 안 찍었어요

지금 찍으세요. 그리고 앨범에서 골라서 업로드하면 됩니다. 같은 작업 흐름입니다.

Q. 한 주소에 계기가 너무 많아요

리스트 위 계기 검색 칸에 끝번호 2자리 이상 입력하면 즉시 필터링됩니다. 중복 정렬 누르면 변대주 묶음으로 정렬도 됩니다.

Q. 작업 중 사람이 부재중이면?

❌ 불가 누르고 불가 사유에 "부재중" 입력. 나중에 다시 방문할 때 같은 주소를 열어 사유를 보고 재시도하세요.

Q. 통신팀이 따로 들어와도 됩니까?

네. 통신팀은 자기 화면(통신팀 시각)이 따로 있어서 계기팀 작업과 영향 없이 별도로 진행합니다. 같은 주소를 동시에 봐도 충돌 없습니다.

🆘 문제 생기면 앱이 멈추거나 이상하면 새로고침 → 안 되면 로그아웃 → 다시 로그인. 그래도 안 되면 캡쳐해서 관리자(우영준)에게 전달해주세요.
