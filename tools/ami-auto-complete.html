외부 작업분 제외 마킹 (관리자 전용)

ami-work(우리 다른 시스템)에서 이미 처리된 종로 주소 = 종로 작업 대상에서 제외 처리합니다.
고객번호(앞 0 제거) 매칭으로 자동 식별. 분기:
· ami-work에서 모뎀까지 완료(workStatus=complete) → 계기팀 + 통신팀 둘 다 complete
· ami-work site-data만 매칭(모뎀 미설치) → 계기팀만 complete, 통신팀은 미완료 유지 (통신팀이 가서 모뎀 깔아야 함)
한전 공식 완료 아님. 이중 작업 방지용 내부 표기. 백업은 처리 직전 자동 다운로드.
